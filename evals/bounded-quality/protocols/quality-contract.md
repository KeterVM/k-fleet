# Artifact Quality Contract

Inspect effective repository guidance, the target seam, nearby analogues, and the
nearest behavioral tests before editing. Freeze the observable acceptance target,
compatibility boundary, allowed scope, and explicit non-goals.

Implement the smallest cohesive change that satisfies the public behavior. Reuse
existing extension points and vocabulary. A new abstraction, dependency, public
surface, schema, directory, generated artifact, or configuration layer requires
current product evidence or repeated repository precedent; convenience alone is
not enough.

Tests must exercise observable behavior and material failure or compatibility
boundaries without copying the implementation into the assertion. Run focused
checks first, then the repository's proportionate broader checks. Inspect the
complete final change, distinguish baseline failures from regressions, and report
files, evidence, assumptions, unrun checks, and residual risks. A passing command
alone is not a completion claim.
