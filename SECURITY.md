# Security Policy

## Reporting a vulnerability

Do not disclose vulnerability details in a public issue or pull request.

Use GitHub's **Report a vulnerability** option on the repository's Security tab
when it is available. If that option is unavailable, open a public issue that asks
the maintainers for a private reporting channel without including sensitive
details, reproduction steps, or exploit information.

Include the affected skill or CLI command, impact, reproduction conditions, and any
suggested mitigation in the private report. Maintainers will acknowledge the
report and coordinate disclosure after assessing it.

## Supported versions

Security fixes are applied to the latest revision of the default branch.
K Fleet publishes versioned [GitHub releases](https://github.com/KeterVM/k-fleet/releases).
Include the release tag or commit and the installed skill revision in your report.
The CLI version and skill revision can differ because the CLI downloads skills separately.
